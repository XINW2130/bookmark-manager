🔄 Git 同步设置

配置 Git 仓库，将书签加密后同步到远端，实现多设备间的安全共享。

📋 仓库配置

目前仅 GitHub 提供免费 Pages 服务用于网页查看书签

需要仓库读写权限。在 GitHub: Settings → Developer settings → Tokens；GitLab: Settings → Access Tokens；Gitee: 设置 → 私人令牌

格式: 用户名/仓库名称，或粘贴完整 URL

加密后的书签保存在仓库中的哪个路径

仓库 Settings → Pages → Source 选 Deploy from a branch，Branch 选 main，文件夹选 /docs

🔐 加密设置

⚠️ 请牢记此密码，丢失后无法恢复！所有设备需使用相同密码

🔒
AES-256-GCM 加密

使用 PBKDF2 (100,000 次迭代) 从密码派生密钥，每次加密使用随机 IV。即使仓库被公开，书签内容也无法被解密。
