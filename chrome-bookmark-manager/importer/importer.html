各浏览器导出方法：

  • Chrome: 书签管理器 → ⋮ 菜单 → 导出书签
  • Edge: 收藏夹 → ⋯ 菜单 → 导出收藏夹
  • Firefox: 书签 → 管理 → 导入和备份 → 导出书签到 HTML
  • Safari: 文件 → 导出 → 书签
  • 360/QQ/搜狗: 收藏夹 → 导入/导出 → 导出书签
