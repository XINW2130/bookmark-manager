# 全浏览器书签管理器 - Chrome 插件

一个功能强大的 Chrome 浏览器扩展，可以汇总展示所有浏览器的书签，并支持外部书签文件的导入与解析。

## 功能特性

### 🔍 书签扫描与汇总
- 自动读取 Chrome 浏览器所有书签
- 树形结构展示，按文件夹分类
- 实时搜索过滤（按名称、URL、文件夹）
- 统计面板（总书签数、文件夹数、外部导入数）

### 📥 外部书签导入
- 支持 **HTML 格式**（Netscape Bookmark File Format）—— 所有主流浏览器通用
- 支持 **JSON 格式**（Chrome 原生导出格式）
- 拖拽上传或点击选择文件
- 支持同时上传多个文件进行批量导入
- 智能 URL 去重，避免重复导入
- 可视化预览，可选择性导入
- 自动识别并标记重复书签

### 📤 书签导出
- 一键导出全部书签为 HTML 格式
- 兼容所有浏览器的导入格式

### 🎨 界面设计
- 现代化 UI 设计，清爽美观
- 文件夹展开/折叠交互
- 书签项 hover 操作按钮（打开、复制链接、删除）
- Toast 消息提示
- 响应式布局

## 安装步骤

### 1. 生成图标
在浏览器中打开 `icons/icon-generator.html`，下载生成的三个 PNG 图标文件，保存到 `icons/` 目录下。

### 2. 加载插件到 Chrome
1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择 `chrome-bookmark-manager` 文件夹
5. 插件安装完成！

## 使用方法

### 查看书签
- 点击浏览器右上角的插件图标，打开弹窗
- 在 **全部书签** 标签页查看所有 Chrome 书签和外部导入书签
- 在 **外部导入** 标签页单独查看从其他浏览器导入的书签
- 使用搜索框快速过滤书签
- 点击书签项可直接打开链接

### 导入外部浏览器书签
1. 首先从其他浏览器导出书签：
   - **Chrome**: 书签 → 书签管理器 → ⋮ → 导出书签
   - **Edge**: 收藏夹 → ⋯ → 导出收藏夹
   - **Firefox**: 书签 → 管理 → 导入和备份 → 导出书签到 HTML
   - **Safari**: 文件 → 导出 → 书签
   - **360/QQ/搜狗浏览器**: 收藏夹 → 导入/导出 → 导出书签

2. 在插件弹窗中点击 **📥 导入外部书签** 按钮
3. 拖拽或选择 HTML 书签文件到上传区域
4. 预览解析结果，勾选/取消需要导入的书签
5. 点击 **导入选中书签**

### 扫描 Chrome 书签
- 点击 **🔍 扫描 Chrome 书签** 按钮刷新当前 Chrome 书签数据
- 点击 **🔄 刷新** 按钮重新加载所有书签

### 导出书签
- 点击弹窗右上角的 **📤 导出** 按钮
- 会自动下载一个 HTML 格式的书签文件

## 技术说明

### 关于"全浏览器书签扫描"
由于 Chrome 扩展程序的安全沙箱限制，插件**无法直接读取其他浏览器的书签文件**。我们采用了以下方案：
1. **Chrome 书签**：通过 `chrome.bookmarks` API 直接读取
2. **其他浏览器书签**：通过用户手动导出 + 插件导入的方式汇总

### 支持的导入格式
- **HTML (Netscape Bookmark File Format)**: 所有主流浏览器都支持导出此格式
- **JSON**: Chrome 原生书签存储格式

## 权限说明
- `bookmarks`: 读取和管理 Chrome 书签
- `storage`: 存储外部导入的书签数据
- `tabs`: 在新标签页中打开书签链接
- `favicon`: 获取网站图标
